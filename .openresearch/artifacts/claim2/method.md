# Claim 2 method

The primary verifier checks the universal order argument using exact rational arithmetic and constructs the smallest strict stage for several nontrivial gaps. The independent checker exhausts every rational value multiset containing two through five policies on denominator grids 2 through 12. It checks that `epsilon_diff/2` admits only optimal policies and separately confirms that equality admits a runner-up. The probability step is event inclusion: the epsilon-optimal event is a subset of the optimal event once the strict gap condition holds.
